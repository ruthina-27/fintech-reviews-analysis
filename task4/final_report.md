# Fintech App Reviews Analysis - Final Report

## 1. Executive Summary
This report analyzes user reviews for three major Ethiopian banking apps (CBE, Bank of Abyssinia, and Dashen Bank) to identify key drivers of satisfaction, pain points, and areas for improvement.

## 2. Key Findings

### 2.1 Bank Comparison
- **Dashen Bank**: Highest average rating (4.34/5)
- **CBE**: Second highest rating (4.07/5)
- **Bank of Abyssinia**: Lowest rating (2.73/5)

### 2.2 Drivers and Pain Points

#### CBE
**Drivers:**
- App functionality and usability
- Good overall banking experience
- Positive customer service interactions

**Pain Points:**
- Network connectivity issues
- Security concerns
- App stability problems

#### Bank of Abyssinia
**Drivers:**
- Basic app functionality
- Simple interface

**Pain Points:**
- Severe app performance issues
- Frequent crashes
- Poor user experience
- Mobile banking reliability

#### Dashen Bank
**Drivers:**
- Super app concept
- Fast and efficient banking
- Easy to use interface
- Comprehensive features

**Pain Points:**
- Occasional slow performance
- Transaction processing delays
- Mobile app stability

## 4. Ethics and Biases

### 4.1 Potential Biases
1. **Selection Bias**: Users with negative experiences are more likely to leave reviews
2. **Time-based Bias**: Reviews might be influenced by recent app updates or events
3. **Language Bias**: Analysis might miss nuances in non-English reviews
4. **Rating Distribution**: Ratings show a bimodal distribution, suggesting polarized user experiences
